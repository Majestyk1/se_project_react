# WTWR (What To Wear Right Now)

## Overview

This project is a React-based front end for the WTWR app. It displays clothing recommendations based on the current weather.

## Features

- Displays clothing cards from a hard-coded data array.
- Fetches weather data from an API and updates the temperature and location.
- Shows the current location in the header.
- Filters clothing based on temperature.
- Modals for adding new garments and viewing clothing images.
- Responsive design following Figma guidelines.
